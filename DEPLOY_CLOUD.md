# FitMe без компьютера: бесплатный облачный режим

Схема: **телефон → бэкенд FitMe на Hugging Face Space (бесплатный CPU) → FASHN VTON 1.5 на бесплатном ZeroGPU**.
Компьютер и Kaggle не нужны. Если Kaggle-ноутбук запущен и его URL настроен, бэкенд сам переключится на него.

## 1. Аккаунт и токен
1. Зарегистрируйтесь на huggingface.co (бесплатно).
2. Settings → Access Tokens → **New token** (тип *Read*) и скопируйте его.

## 2. Space с бэкендом
1. huggingface.co → **New Space** → SDK: **Docker** → *Blank* → Hardware: **CPU basic (free)** → Public.
2. Загрузите в Space (Files → Add file → Upload files) содержимое папки `backend/`:
   - `app/` (вся папка), `requirements.txt`, `requirements-cutout.txt`, `Dockerfile`;
   - `SPACE_README.md` переименуйте в **`README.md`** (в нём заголовок с `sdk: docker` и `app_port: 7860`).
3. Settings → **Variables and secrets** → New secret: `HF_TOKEN` = ваш токен.
4. Дождитесь статуса **Running**. Адрес бэкенда: `https://<ваш-ник>-<имя-space>.hf.space`.
   Проверка: откройте `.../health`, должно быть `"status":"online"`.

## 3. APK для телефона
На компьютере с Flutter один раз запустите `BUILD_APK.bat` и вставьте адрес из шага 2.
Готовый файл `build\app\outputs\flutter-apk\app-release.apk` скиньте на телефон и установите.
После этого приложение работает без компьютера.

## Ограничения бесплатного режима
- GPU: ZeroGPU даёт около 5 минут в день на бесплатный аккаунт (около 40 минут с PRO за $9/мес). Одна примерка занимает примерно 10–25 с GPU, то есть получается порядка 15–25 примерок в день.
  Когда лимит кончается, приложение показывает понятную ошибку.
- Хранение: каталог и образы лежат во временной папке Space и пропадают при перезапуске.
  Постоянное хранение появится вместе с регистрацией пользователей (облачная база данных, следующий этап).
- Бесплатный Space засыпает после 48 часов без запросов. Первый запрос после сна ждёт около минуты.
