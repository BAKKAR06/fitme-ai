# Подключение FitMe к Firebase (≈10 минут, бесплатно)

Firebase хранит аккаунты (почта + пароль), сам отправляет письма «подтвердите почту» и «новый пароль»,
а в базе Firestore лежат профили, роли, каталоги, луки и список примерок. Ноутбук по-прежнему делает
примерки и считает нагрузку видеокарты.

## 1. Создать проект
1. Откройте https://console.firebase.google.com и войдите своим Google-аккаунтом.
2. **Create a project** → имя `FitMe` → Google Analytics можно выключить → **Create project**.

## 2. Включить вход по почте
1. Слева **Build → Authentication → Get started**.
2. Вкладка **Sign-in method** → **Email/Password** → включить первый переключатель → **Save**.
3. (по желанию) Вкладка **Templates** → значок карандаша → **Template language: Russian** — письма будут по-русски.

## 3. Создать базу Firestore
1. Слева **Build → Firestore Database → Create database**.
2. Location: `eur3 (Europe)` (или ближайший), режим **Production mode** → **Create**.
   Правила менять не нужно: приложение ходит в базу только через ваш сервер.

## 4. Ключ сервера (секретный — никому не отправляйте)
1. Шестерёнка ⚙ → **Project settings → Service accounts** → **Generate new private key** → **Generate key**.
2. Скачанный файл переименуйте в `firebase-service-account.json` и положите в
   `D:\fitme-ai\backend\data\` (в GitHub он не попадёт).

## 5. Ключ приложения (не секретный)
1. **Project settings → General** → в блоке **Your project** скопируйте **Web API Key**.
   Если его нет: внизу **Your apps → </> (Web)** → любое имя → **Register app**, ключ появится.
2. Дважды щёлкните `SETUP_FIREBASE.bat`, вставьте ключ, Enter. Должно быть два **OK** и **READY**.

## 6. Собрать и запустить
1. `BUILD_APK_ONLY.bat` — новое приложение с ключами Firebase (`FitMe.apk`).
2. `START_LOCAL_GPU.bat` — серверы.
3. Установите APK, **зарегистрируйтесь первым** — первый аккаунт становится «Создателем».
   Подтвердите почту по ссылке из письма и нажмите «Я подтвердил почту».

## Где смотреть данные
- **Authentication → Users** — все аккаунты, можно отключить или удалить.
- **Firestore Database** — коллекции `users` (профиль, роль, счётчики), `users/{id}/catalog`, `users/{id}/looks`,
  `tryons` (каждая примерка), `config/app` (регистрация открыта, лимит примерок).
- Сделать человека админом: в приложении «Админ-панель → Пользователи» или в Firestore поле `role` = `admin`.
- Нагрузка видеокарты и трафик — в админ-панели (они остаются на ноутбуке, это тысячи записей в день,
  бесплатный Firestore на такое не рассчитан).

Бесплатного тарифа Spark хватает: 50 000 чтений и 20 000 записей в день, вход — без ограничений по числу пользователей.
